# 配置说明

只在插件自己的配置页填写。不要把真实配置提交到 GitHub。

| 设置 | 默认值 | 说明 |
|---|---|---|
| `platform_id` | "" | 在 AstrBot「机器人」页面复制的 QQ / OneBot 平台实例 ID，首次安装必须填写。 |
| `default_rules` | 见下表 | 未单独设置的群沿用这一套默认规则。 |
| `group_rules` | [] | 各群单独回复规则 |
| `allowed_groups` | [] | 高级：插件生效群号或会话ID（空列表为全部群） |
| `stale_chat_groups` | [] | 高级：跳过排队过久的概率闲聊的群号 |
| `stale_chat_seconds` | 30 | 高级：概率闲聊最大排队时间（秒） |

## 默认规则与单群覆盖

推荐从本插件的「插件视图 → 回复规则」页面选择群聊，直接修改并保存。

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| `chat_percent` | 20 | 普通消息自动回复概率 |
| `image_percent` | 100 | 普通图片自动回复概率 |
| `bilibili_percent` | 100 | B站视频自动回复概率 |
| `heybox_percent` | 100 | 小黑盒帖子自动回复概率 |
| `forward_percent` | 100 | 转发聊天记录自动回复概率 |
| `reply_limit_per_minute` | 0 | 每群最近 60 秒内成功发送的 QQ 消息条数上限，0 不限制，允许 0–600 的整数；单群可填 -1 继承。真正 @不占额度；分开发送的文字、语音和表情各计一条，合并在同一条 QQ 消息中计一条。 |
| `at_only_users` | [] | 仅被真正 @ 时回复的用户 QQ 号列表 |

默认概率填写 0–100。单群 `group_rules` 中的同名概率可填写 `-1` 表示继承默认，填写 `0` 表示关闭该类消息的自动回复；真正 @ 和唤醒请求仍然处理。

单群名单的 `at_only_mode` 可选「继承默认」或「单独设置」。选择「单独设置」后，`at_only_users` 替换默认名单，留空表示该群不限制任何用户。

`at_only_users` 只限制回复，不屏蔽该用户在群聊上下文中的发言。请同时开启 AstrBot 的群聊上下文功能；文本记录和历史图片的描述方式仍由 AstrBot 配置决定。

`stale_chat_seconds` 只在 `stale_chat_groups` 指定的群中生效；名单留空时，尚未为任何群启用过期闲聊保护。
