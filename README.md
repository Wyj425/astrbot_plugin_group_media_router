# 群聊媒体回复规则

**给每个 QQ 群单独设置机器人什么时候接话：闲聊少回、图片多回，也可以让指定用户只有 @机器人时才收到回复。**

先设一套默认规则，再为需要区别对待的群修改个别设置。未单独设置的群会自动沿用默认值。

<img src="logo.png" width="120" alt="群聊媒体回复规则插件图标">

## 能做什么

- 分别设置普通消息、图片、B站视频、小黑盒帖子和转发聊天记录的自动回复概率。
- 每个群单独调整概率，也可以继续继承默认值。
- 设置每群最近一分钟内实际发出的自动回复消息条数，真正 @机器人的回复豁免且不占额度。
- 按 QQ 号设置「仅被 @ 时回复」的用户名单。
- 根据 QQ 提供的表情标记，区分普通图片与部分表情消息。
- 对指定群跳过排队过久的自动闲聊回复，减少话题已经过去才接话的情况。

适用于 **AstrBot 4.29.3 及以上、Python 3.12，QQ / OneBot 接入**。当前已验证 AstrBot 4.29.3。

## 安装与配置

1. 在 **AstrBot → 插件市场** 搜索「群聊媒体回复规则」，点击安装。
2. 在 **AstrBot → 机器人** 找到已连接的 QQ / OneBot 机器人，复制它的 **平台实例 ID**。
3. 在 **插件 → 群聊媒体回复规则 → 配置** 中，将该 ID 填入 `platform_id` 并保存。
4. 打开本插件的 **插件视图 → 回复规则**，开始设置默认规则和单群规则。

所需 Python 依赖使用 AstrBot 的运行环境，正常使用时无需额外部署服务或登录第三方平台。

## 设置默认规则

在「回复规则」页面的 **设置范围** 中选择默认规则，调整概率后保存。

| 消息类型 | 默认自动回复概率 |
| --- | --- |
| 普通文字 | 20% |
| 普通图片 | 100% |
| B站视频 | 100% |
| 小黑盒帖子 | 100% |
| 转发聊天记录 | 100% |

概率填写 **0–100**：例如 20 表示约五条普通消息中随机选中一条，实际短期频率会有波动。

**0% 表示不自动接话，100% 表示全部参与自动回复选择，仍受自动回复频率上限约束。真正 @机器人或通过唤醒指令触发的请求不受概率筛选。** 读取失败、模型错误等仍可能使一次处理没有得到回复。

## 一分钟内最多自动回复几条

在「回复规则 → 自动回复频率」中设置 **每分钟最多回复**。每个群单独统计最近 60 秒内成功发送的 QQ 消息条数，各群互不占用额度。

- 填 `3`：同一群最近一分钟最多自动发送 3 条 QQ 消息。达到上限后略过剩余分段和新的自动接话，不排队补发。
- 填 `0`：不限制。新安装和旧配置升级默认都不启用此上限。
- 真正 @机器人的回复始终豁免，也不占自动回复次数；手打“@昵称”、@全体和仅引用机器人消息不会获得这项豁免。
- 一轮回复中的文字、语音和表情如果分成不同消息发送，每条分别计数；合并在同一条 QQ 消息中的多个内容只计一条。未触发回复、空回复和发送失败不占额度。

默认规则可为所有群设置同一个上限，但计数仍各自独立。单群可以填写自己的数值，也可以勾选「沿用默认」；普通配置中的 `reply_limit_per_minute` 填 `-1` 表示继承。

## 给某个群单独设置

1. 在 **设置范围** 里选择目标群。
2. 开启 **为此群单独设置**。
3. 只修改需要不同的项目，其他项目保持 **沿用默认**。
4. 保存设置，检查页面显示的实际生效值。

例如：默认闲聊 20%、图片 100%；游戏群可以改为闲聊 50%、图片 60%，工作群改为闲聊 0%、图片 0%。两个群仍然可以通过 @机器人主动提问。

在普通配置页直接编辑 `group_rules` 时，各群概率填 `-1` 表示沿用默认，填 `0` 表示关闭对应类型的自动回复。

## 指定用户仅在 @ 时回复

1. 选择默认规则或某个群的规则。
2. 在 **仅被 @ 时回复的用户** 中填写 QQ 号，每行一个。
3. 单群名单可以选择 **沿用默认名单**，也可以改为 **单独设置**。
4. 保存后，该名单中的用户需要真正 @机器人，才会收到回复。

名单按 QQ 号识别，用户改昵称也会生效。使用 QQ 的成员选择完成 @；手打“@昵称”和 @全体不算。单群选择「单独设置」且名单留空，表示这个群不限制任何用户，覆盖默认名单。

## 图片和表情如何区分

QQ 明确标记为表情、动画表情或商城表情的**纯表情消息**，不会按普通图片概率自动触发。

如果群友把表情包保存成普通图片再发送，QQ 可能只提供图片标记，这种情况仍会按普通图片处理。这个分类依据消息标记，无法保证识别每一张图片是否属于表情包。

## 排队过久的闲聊

在插件配置中设置：

| 设置 | 用途 | 默认值 |
| --- | --- | --- |
| `stale_chat_groups` | 启用排队保护的群号列表 | 空列表，尚未指定群 |
| `stale_chat_seconds` | 自动闲聊可等待的时间 | 30 秒 |

将需要保护的群号加入 `stale_chat_groups`，超过设定时间的概率闲聊会静默跳过。@机器人、明确问题、指令和媒体消息会继续处理。

## 常见问题

**页面没有群列表或规则不生效？**

检查 `platform_id` 是否与「机器人」页面中的实例 ID 一致、QQ 接入是否在线，再点「重新读取」。高级配置 `allowed_groups` 留空时规则适用于所有群，填写后只在所列群生效。

**会修改私聊的回复概率吗？**

本插件的回复概率与仅 @ 名单针对群聊，私聊使用 AstrBot 自己的会话设置。

**设了 100%，为什么视频还是只知道标题？**

回复概率控制是否处理消息。理解视频或帖子的正文需要相应的内容读取能力；查看图片还需要支持视觉的聊天模型。可以按需要安装对应的读取插件并完成登录。

**会额外调用模型吗？**

分类、概率判断和名单检查在本地完成，不会单独调用语言模型。被选中后，正常回答仍会使用聊天模型；自动回复概率越高，可能产生的聊天请求越多。

## 数据与备份

规则保存在 `data/config/group_media_router_config.json`。备份、恢复这一配置文件即可保存默认规则和各群设置。卸载插件后，群聊的触发方式由 AstrBot 当前设置决定。
